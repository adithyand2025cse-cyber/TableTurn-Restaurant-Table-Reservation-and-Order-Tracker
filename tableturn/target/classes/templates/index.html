About TableTurn

TableTurn is a restaurant management system designed to simplify table reservations, order management and billing operations.

The system uses Spring Boot for the backend, JPA for database operations and a responsive web interface for restaurant staff and customers.

Restaurant administrators can manage tables, reservations, orders and bills from one centralized system.
